# Contributing

Thanks for helping keep this directory accurate!

## What belongs here

- A project, company, or program that **rewards open-source contributions** with anything: 👕 swag, 💰 cash/bounties, 🏆 stipends, 💼 jobs/hiring pipelines.
- Entries must link to **the source of the claim** (project README, program page, official announcement).

## Rules

1. **Verify before adding** — link the page that states the reward/criteria.
2. **No referral/affiliate links.** Ever.
3. **State the status**: `Live` (with date), `Evergreen`, or `⚠️ historical` (with year).
4. **Describe what counts** — exactly what contribution qualifies.
5. One entry per line; keep the table format.
6. Be respectful: this list is not a reason to spam maintainers. Projects flagged as "meaningful contributions only" mean it.

## Format

### Swag table

```
| **Project** | [org/repo](https://github.com/org/repo) | 👕 Reward | What counts | Status |
```

### Jobs table

```
| Company | [org/repo](https://github.com/org/repo) | [Apply](careers-url) |
```

### Programs table

```
| Program | Pay | Next window | Notes |
```

## How to submit

Open a PR with the changed table row(s) + a one-line justification in the PR description (with the source link). If a reward has expired, mark it `⚠️ historical` instead of deleting — history is useful.
